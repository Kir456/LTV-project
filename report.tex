	\section{Описание задачи и данных}
	
	\subsection{Постановка задачи}
	
	Задача --- предсказание \textbf{Customer Lifetime Value (LTV)} на горизонте 30 дней.
	Модель должна по истории активности пользователя предсказать суммарный GMV
	за период с 14.02.2026 по 15.03.2026.
	
	\begin{dangerbox}
		\textbf{Публичный / Приватный лидерборд: 20\% / 80\%!}\\
		Оценка на публичном лидерборде вычисляется только по 50\,000 из 250\,000 клиентов.
		Это означает высокий риск \emph{public-private shake-up}.
	\end{dangerbox}
	
	\textbf{Метрика качества:}
	\[
	\mathrm{RMSLE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}\bigl(\log(1+\hat{y}_i) - \log(1+y_i)\bigr)^2}
	\]
	
	\subsection{Особенности исходных данных}
	
	\begin{infobox}
		\textbf{Объём:} 30+ млн записей, 250\,000 клиентов\\
		\textbf{Период:} 01.01.2025 -- 13.02.2026 (407 дней)\\
		\textbf{Тип:} Прореженные временные ряды (спарс).
	\end{infobox}
	
	Особенности целевой переменной: данные сильно \textbf{zero-inflated}. Около 45.1\% пользователей в обучающей выборке не совершают ни одной покупки (target = 0).

	\section{Схема валидации: Walk-Forward Cross-Validation}
	
	Для временных рядов используется строго \textbf{Walk-Forward CV}.
	Тестировались два подхода к формированию обучающей выборки:
	\begin{enumerate}
		\item \textbf{Single-Fold:} обучение только на предыдущем фолде ($\mathcal{D}_{val-1} \to \mathcal{D}_{val}$). Подход показал наилучшую устойчивость.
		\item \textbf{Cumulative:} обучение на всех исторических фолдах ($\bigcup_{j=0}^{val-1} \mathcal{D}_j \to \mathcal{D}_{val}$).
	\end{enumerate}
	
	Параметр \texttt{stride} (шаг смещения anchor date) критически влияет на качество. При $stride=7$ и $target=30$ возникало 77\%-е перекрытие таргетов между фолдами, что приводило к сильному переобучению алгоритмов (в частности, Optuna). Оптимальным решением признан $stride=14$.

	\section{Альтернативные подходы: BTYD и Two-Stage}
	
	Для решения проблемы завышенных нулей (zero-inflation) были реализованы специализированные подходы.
	
	\subsection{BTYD (BG/NBD + Gamma-Gamma)}
	Классическая вероятностная модель поведения покупателей (ноутбук \texttt{7\_btyd.ipynb}). 
	Модель BG/NBD оценивала частоту покупок и вероятность оттока $P(alive)$, а Gamma-Gamma --- средний чек.
	\textbf{Результат:} Модель сильно завысила ожидания. Средний предсказанный LTV составил 85.17, что критически оторвано от реальности лучших ML-моделей (средний предикт $\approx 35.35$). Отправка чистого сабмита признана нецелесообразной.
	
	\subsection{Two-Stage Model}
	Двухэтапная архитектура (ноутбук \texttt{6\_two\_stage.ipynb}):
	\begin{itemize}[nosep]
		\item \textbf{Stage 1:} CatBoostClassifier предсказывает $P(GMV > 0)$.
		\item \textbf{Stage 2:} CatBoostRegressor обучается \emph{только} на покупателях ($E[GMV | buy]$).
	\end{itemize}
	\textbf{Результат:} Как самостоятельная модель Two-Stage проиграла бейзлайну (лучший RMSLE: 1.90800). Однако \textbf{Stage 1 классификатор дал важнейший инсайт}: анализ показал, что оптимальный порог вероятности покупки составляет $P(buy) = 0.46$.
	
	\begin{successbox}
		\textbf{Метод «Zero-Hack»:}\\
		Предсказания $P(buy)$ из классификатора можно использовать как маску для лучших регрессоров. Зануление предиктов пользователей с $P(buy) < 0.46$ локально улучшило RMSLE модели Two-Stage с 2.04 до 1.90. Этот хак будет применён к финальному ансамблю.
	\end{successbox}

	\subsection{Философия признакового пространства v4}
	\begin{enumerate}
		\item \textbf{Окна полной истории:} добавлены агрегации за 270d и 365d.
		\item \textbf{Новые срезы:} \texttt{gmv\_search}, \texttt{gmv\_cat}, флаги \texttt{search}/\texttt{cat}.
		\item \textbf{RFM-метрики:} добавлены frequency (\texttt{freq\_cart}, \texttt{active\_days}) и recency (\texttt{recency\_cart\_days}, \texttt{user\_age\_days}).
		\item \textbf{Схема валидации:} возврат к $stride=14$ (золотая середина) и \textbf{Single-Fold} обучению.
	\end{enumerate}
	
	\subsection{CatBoost v4a Baseline}
	Схема Single-Fold (без переобучающего cumulative-накопления) на новых 392 фичах выдала рекордный результат. Модель самостоятельно отбирала признаки без принудительного Feature Selection.

	\section{Стратегия финальных ансамблей (5 сабмитов)}
	
	Учитывая доступный лимит в 5 отправок, стратегия построена на использовании чемпиона \textbf{CatBoost v4a} в качестве базы. Внутривидовые бленды (Single + Cumulative) отменены из-за идентичности датасетов при $N\_FOLDS=2$.
	
	\textbf{Файлы для загрузки на Лидерборд:}
	\begin{enumerate}
		\item \textbf{Ортогональный бленд v1:} 85\% CatBoost v4a + 15\% RNN v2.
		\\Нейросеть сгладит редкие выбросы бустинга благодаря своей ортогональности.
		\item \textbf{Ортогональный бленд v2:} 90\% CatBoost v4a + 10\% RNN v2.
		\item \textbf{Zero-Hack Champion:} Чистый предикт CatBoost v4a, в котором принудительно установлены нули для пользователей с $P(buy) < 0.46$ (маска от классификатора).
		\item \textbf{LightGBM v4 (Соло):} Модель LightGBM, обученная на новых мощных признаках v4.

	\addcontentsline{toc}{section}{Приложение: Ключевые формулы}
	
	\subsection*{Оценка качества (RMSLE)}
	\[
	\mathrm{RMSLE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}\bigl(\log(1+\hat{y}_i) - \log(1+y_i)\bigr)^2}
	\]
	
	\subsection*{Log-трансформация}
	\[
	\tilde{y} = \log\!\bigl(1 + \max(y,\,0)\bigr),\qquad
	\hat{y} = \max\!\bigl(e^{\hat{\tilde{y}}} - 1,\;0\bigr)
	\]
	
	\subsection*{Tie-breaker: Gini Normalized}
	\[
	G_{norm} = \frac{G(\hat{y},y)}{G(y,y)}
	\qquad
	G(a,b) = \frac{1}{n}\left(\frac{\sum_i b_{[a_i\downarrow]}\cdot i}{\sum_i b_i} - \frac{n+1}{2}\right)
	\]
