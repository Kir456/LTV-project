	\section{Описание задачи и данных}
	
	\subsection{Постановка задачи}
	
	Задача --- предсказание \textbf{Customer Lifetime Value (LTV)} на горизонте 30 дней.
	Модель должна по истории активности пользователя предсказать суммарный GMV
	за период с 14.02.2026 по 15.03.2026.
	
	\begin{dangerbox}
		\textbf{Публичный / Приватный лидерборд: 20\% / 80\%!}\\
		Оценка на публичном лидерборде вычисляется только по 50\,000 из 250\,000 клиентов.
		Это означает высокий риск \emph{public-private shake-up}.
	\end{dangerbox}
	
	\textbf{Метрика качества:}
	\[
	\mathrm{RMSLE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}\bigl(\log(1+\hat{y}_i) - \log(1+y_i)\bigr)^2}
	\]
	
	\subsection{Особенности исходных данных}
	
	\begin{infobox}
		\textbf{Объём:} 30+ млн записей, 250\,000 клиентов\\
		\textbf{Период:} 01.01.2025 -- 13.02.2026 (407 дней)\\
		\textbf{Тип:} Прореженные временные ряды (спарс).
	\end{infobox}
	
	Особенности целевой переменной: данные сильно \textbf{zero-inflated}. Около 45.1\% пользователей в обучающей выборке не совершают ни одной покупки (target = 0).

	\section{Схема валидации: Walk-Forward Cross-Validation}
	
	Для временных рядов используется строго \textbf{Walk-Forward CV}.
	Тестировались два подхода к формированию обучающей выборки:
	\begin{enumerate}
		\item \textbf{Single-Fold:} обучение только на предыдущем фолде ($\mathcal{D}_{val-1} \to \mathcal{D}_{val}$). Подход показал наилучшую устойчивость.
		\item \textbf{Cumulative:} обучение на всех исторических фолдах ($\bigcup_{j=0}^{val-1} \mathcal{D}_j \to \mathcal{D}_{val}$).
	\end{enumerate}
	
	Параметр \texttt{stride} (шаг смещения anchor date) критически влияет на качество. При $stride=7$ и $target=30$ возникало 77\%-е перекрытие таргетов между фолдами, что приводило к сильному переобучению алгоритмов (в частности, Optuna). Оптимальным решением признан $stride=14$.

	\section{Эволюция признакового пространства}
	
	В процессе разработки пайплайн прошёл через несколько итераций, выявивших ключевые зависимости. 
	Финальным прорывом стала итерация \textbf{v4}, где были применены следующие принципы:
	\begin{enumerate}
		\item \textbf{Окна полной истории:} добавлены агрегации за 270d и 365d (использование всей истории в 407 дней).
		\item \textbf{Новые срезы:} \texttt{gmv\_search}, \texttt{gmv\_cat}, бинарные флаги \texttt{search}/\texttt{cat}.
		\item \textbf{RFM-метрики:} добавлены frequency (\texttt{freq\_cart}, \texttt{active\_days}) и recency (\texttt{recency\_cart\_days}, \texttt{user\_age\_days}).
	\end{enumerate}
	
	Анализ Feature Importance выявил абсолютное доминирование долгосрочных агрегатов (365d, 270d) и метрик недавности (\texttt{recency\_ord\_days}).

	\section{Архитектура базовых моделей}
	
	\subsection{CatBoostRegressor (Чемпион)}
	Градиентный бустинг с \emph{level-wise} построением деревьев. Обучение производилось по схеме \textbf{Single-Fold} на 392 признаках v4. Модель отлично справилась с извлечением сложных нелинейных зависимостей из агрегатов, выдав лучший одиночный результат \rmsleGood{1.66049}.
	
	\subsection{LightGBM}
	Градиентный бустинг с \emph{leaf-wise} сплитом. Настроен через Optuna с использованием тех же данных (v4). Благодаря другой архитектуре построения деревьев, модель формирует иное распределение ошибок, что отлично подходит для внутривидовой диверсификации бустингов.
	
	\subsection{Рекуррентная нейронная сеть (PyTorch GRU)}
	В отличие от бустингов, которые оперируют статичными историческими агрегатами (sum, max, mean), \textbf{RNN учитывает секвенциальную природу данных}. 
	
	\textbf{Архитектура:}
	\begin{itemize}[nosep]
		\item \textbf{Input:} Временные ряды (\texttt{SEQ\_LEN=120} дней) по 10 признакам (действия в каталоге, поиске, корзине, GMV).
		\item \textbf{Core:} 3-слойный GRU (hidden\_dim=192, dropout=0.3).
		\item \textbf{Head:} Fully Connected слои с LayerNorm и GELU активациями.
		\item \textbf{Обучение:} Optimizer AdamW + CosineAnnealingLR, Loss: MSE на log1p таргете.
	\end{itemize}
	
	\begin{successbox}
		\textbf{Роль RNN в пайплайне:}\\
		Анализ ансамблей показал, что CatBoost и LightGBM коррелируют между собой на $\approx 0.99$ (они практически идентичны). Однако корреляция Пирсона между CatBoost и RNN составляет всего $\approx 0.93$. Именно RNN обеспечивает необходимую \textbf{ортогональность ошибок}, что делает её идеальным компонентом для финальных блендов.
	\end{successbox}

	\section{Альтернативные подходы: BTYD и Two-Stage}
	
	Для решения проблемы завышенных нулей (zero-inflation) были протестированы специализированные подходы.
	
	\subsection{BTYD (BG/NBD + Gamma-Gamma)}
	Классическая вероятностная модель поведения покупателей (ноутбук \texttt{7\_btyd.ipynb}). 
	Модель BG/NBD оценивала частоту покупок и вероятность оттока $P(alive)$, а Gamma-Gamma --- средний чек.
	\textbf{Результат:} Модель сильно завысила ожидания (средний предсказанный LTV = 85.17, против $\approx 35.35$ у CatBoost). Отправка чистого сабмита признана нецелесообразной.
	
	\subsection{Two-Stage Model и метод «Zero-Hack»}
	Двухэтапная архитектура (ноутбук \texttt{6\_two\_stage.ipynb}):
	\begin{itemize}[nosep]
		\item \textbf{Stage 1:} \texttt{CatBoostClassifier} предсказывает $P(GMV > 0)$.
		\item \textbf{Stage 2:} \texttt{CatBoostRegressor} обучается \emph{только} на покупателях ($E[GMV | buy]$).
	\end{itemize}
	Как самостоятельная модель Two-Stage проиграла бейзлайну. Однако классификатор из \textbf{Stage 1} дал важнейший инсайт: оптимальный порог вероятности покупки составляет $P(buy) = 0.46$.
	
	\begin{infobox}
		\textbf{Внедрение «Zero-Hack»:}\\
		Предсказания $P(buy)$ из классификатора используются как маска. Зануление предиктов пользователей с $P(buy) < 0.46$ спасает регрессоры от штрафа за предсказание мелких сумм для "спящих" клиентов. Этот метод применяется поверх лучших ML-предсказаний.
	\end{infobox}

	\textbf{Файлы для загрузки на Лидерборд:}
	\begin{enumerate}
		\item \textbf{Ортогональный бленд v1:} 85\% CatBoost v4a + 15\% RNN v2.
		\\Нейросеть сгладит редкие выбросы бустинга благодаря своей ортогональности.
		\item \textbf{Ортогональный бленд v2:} 90\% CatBoost v4a + 10\% RNN v2.
		\item \textbf{Zero-Hack Champion:} Чистый предикт CatBoost v4a, в котором принудительно установлены нули для пользователей с $P(buy) < 0.46$ (маска от классификатора).
		\item \textbf{LightGBM v4 (Соло):} Модель LightGBM, обученная на новых мощных признаках v4. 
		\item \textbf{Мощный Бустинг-Бленд:} 60\% CatBoost v4a + 40\% LightGBM v4. 
		\\Диверсификация за счёт комбинации алгоритмов level-wise и leaf-wise сплита.
	\end{enumerate}

	\addcontentsline{toc}{section}{Приложение: Ключевые формулы}
	
	\subsection*{Оценка качества (RMSLE)}
	\[
	\mathrm{RMSLE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}\bigl(\log(1+\hat{y}_i) - \log(1+y_i)\bigr)^2}
	\]
	
	\subsection*{Log-трансформация}
	\[
	\tilde{y} = \log\!\bigl(1 + \max(y,\,0)\bigr),\qquad
	\hat{y} = \max\!\bigl(e^{\hat{\tilde{y}}} - 1,\;0\bigr)
	\]
	
	\subsection*{Tie-breaker: Gini Normalized}
	\[
	G_{norm} = \frac{G(\hat{y},y)}{G(y,y)}
	\qquad
	G(a,b) = \frac{1}{n}\left(\frac{\sum_i b_{[a_i\downarrow]}\cdot i}{\sum_i b_i} - \frac{n+1}{2}\right)
	\]
