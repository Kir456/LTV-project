# LTV Prediction Hackathon

Репозиторий содержит решение задачи предсказания Customer Lifetime Value (LTV) пользователей на горизонте 30 дней на основе их активности в Поиске и Каталоге.

**Лучший скор на публичном лидерборде:** 1.66049 (CatBoost v4a Baseline)

## Описание задачи
Для каждого из 250 000 пользователей необходимо предсказать суммарную выручку (GMV) за период с 14.02.2026 по 15.03.2026. Данные представляют собой сильно прореженные временные ряды (zero-inflated, около 45% пользователей не совершают покупок в тестовом периоде).

**Метрика оценки:** RMSLE (Root Mean Squared Log Error).  
**Tie-breakers:** Нормализованный Gini и RMSPE тотального GMV.

## Архитектура решения
Решение построено на концепции **Walk-Forward Cross-Validation** с шагом (stride) 14 дней для избежания утечек данных (target leakage). 

### Пайплайн обработки:
1. **Feature Engineering (Polars):** Агрегация временных окон (3, 7, 14, 30, 60, 90, 180, 270, 365 дней). Генерация recency, frequency, конверсионных метрик и AOV. Итог: 392 признака.
2. **Моделирование:**
   - **CatBoostRegressor** (Level-wise boosting)
   - **LightGBM** (Leaf-wise boosting для ортогональности предсказаний)
   - **GRU / RNN** (Нейронная сеть на PyTorch для учета секвенциальной природы данных)
3. **Ансамблирование:**
   - Линейное взвешивание ортогональных предсказаний (CatBoost + RNN, CatBoost + LGBM).
   - "Zero-Hack": Использование CatBoostClassifier (Stage 1) для фильтрации пользователей с вероятностью покупки P(buy) < 0.46.

## Как запустить

1. Установите зависимости:
   pip install -r requirements.txt

2. Поместите исходный файл train.parquet в папку data/raw/.

3. Запустите ноутбук notebooks/8_data_v4_2.ipynb для генерации фичей.

4. Обучите базовые модели: CatBoost (9_catboost_v4_2.ipynb), LightGBM (4_train_lightgbm_2.ipynb).

5. Для финального результата запустите генерацию ансамблей в notebooks/5_ensemble_2.ipynb.

## Аппаратное обеспечение
Пайплайн оптимизирован для работы на локальном GPU.
Обучение и тюнинг (Optuna) производились на NVIDIA RTX 4050 Laptop (6 ГБ VRAM). Узким горлышком является оперативная память при загрузке полных фолдов, поэтому применена Single-Fold схема валидации.
