# LTV Prediction Hackathon

Репозиторий содержит решение задачи предсказания Customer Lifetime Value (LTV) пользователей на горизонте 30 дней на основе их активности в Поиске и Каталоге.

**Лучший скор на публичном лидерборде:** 1,6530581463454792

## Описание задачи
Для каждого из 250 000 пользователей необходимо предсказать суммарную выручку (GMV) за период с 14.02.2026 по 15.03.2026. Данные представляют собой сильно прореженные временные ряды (zero-inflated, около 45% пользователей не совершают покупок в обучающей выборке).

**Метрика оценки:** RMSLE (Root Mean Squared Log Error).  
**Tie-breakers:** Нормализованный Gini и RMSPE тотального GMV.

## Архитектура решения: Трехглавый Мета-Ансамбль (v6 Data-Centric)
Решение построено на концепции **Walk-Forward Cross-Validation** (5 фолдов) с шагом (stride) 14 дней для избежания утечек данных (look-ahead bias). Итоговый пайплайн включает объединение (Blending) трёх принципиально разных SOTA-архитектур, обученных на глубоко очищенных данных.

1. **Feature Engineering & Data Cleaning (Polars):** 
   - Агрегация временных окон до 365 дней (435 признаков). 
   - **Target Capping:** Жесткая винзоризация целевой переменной на отметке 4000 (99.9-й перцентиль) для защиты от аномальных "китов".
   - **Gaps & Dormancy:** Обработка отсутствующих межпокупочных интервалов значением `999.0` (вместо негативных) и внедрение бинарных флагов `is_single_buyer` и `is_dormant` (спячка > 120 дней).
2. **Базовые алгоритмы:**
   - **CatBoostRegressor (Seed Averaging):** Level-wise бустинг на 5 разных сидах (`depth=6`, `iterations=2000`) для минимизации дисперсии. Основной фундамент бленда.
   - **Tabular MLP (ZILN Loss):** Нейросеть с кастомной функцией потерь Zero-Inflated Lognormal и `QuantileTransformer` для сглаживания выбросов. Главный бенефициар очистки данных v6.
   - **XGBoost (Log Target):** Асимметричный бустинг с глубокой L1/L2 регуляризацией для диверсификации предсказаний.
3. **Финальный Ансамбль (Сабмит №1 - Безопасный):**
   - Арифметический взвешенный бленд (**70% CatBoost + 20% MLP + 10% XGBoost**) на основе анализа OOF-метрик и ортогональности ошибок. 
4. **Учет сезонности / Seasonal Concept Drift (Сабмит №2 - Рискованный):**
   - Тестовый период выпадает на весенние праздники (14 февраля — 15 марта). Аналитика исторических логов 2025 года показала аномальный рост конверсии в этот месяц. Применение расчетного калибровочного множителя (**1.12375**) ко всем предсказаниям ансамбля позволило компенсировать недооценку LTV и максимизировать метрику на лидерборде.

## Как запустить

1. Установите зависимости: `pip install -r requirements.txt`
2. Поместите исходный файл `train.parquet` в папку `data/raw/`.
3. Запустите ноутбук `notebooks/1_data_v6.ipynb` для генерации вычищенных фичей по 5 фолдам.
4. Выполните `notebooks/2_train_blend_v6.ipynb` для обучения всех моделей и создания базового чистого сабмита.
5. Запустите `notebooks/3_extra_tests.ipynb`, чтобы применить поправочный праздничный коэффициент (1.12375) и получить итоговый файл для отправки на платформу.
