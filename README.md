# LTV Prediction Hackathon

Репозиторий содержит решение задачи предсказания Customer Lifetime Value (LTV) пользователей на горизонте 30 дней на основе их активности в Поиске и Каталоге.

**Лучший скор на публичном лидерборде:** 1.65590

## Описание задачи
Для каждого из 250 000 пользователей необходимо предсказать суммарную выручку (GMV) за период с 14.02.2026 по 15.03.2026. Данные представляют собой сильно прореженные временные ряды (zero-inflated, около 45% пользователей не совершают покупок в тестовом периоде).

**Метрика оценки:** RMSLE (Root Mean Squared Log Error).  
**Tie-breakers:** Нормализованный Gini и RMSPE тотального GMV.

## Архитектура решения: Трехглавый Мета-Ансамбль (v5)
Решение построено на концепции **Walk-Forward Cross-Validation** (5 фолдов) с шагом (stride) 14 дней для избежания утечек данных. Итоговый пайплайн включает объединение (Stacking) трёх принципиально разных SOTA-архитектур.

1. **Feature Engineering (Polars):** Агрегация временных окон до 365 дней. Генерация сложных признаков: межпокупочные интервалы (gaps), дисперсия регулярности покупок, lifecycle trajectories (ускорение заказов) и channel migration. Итог: 435 признаков.
2. **Базовые алгоритмы:**
   - **CatBoostRegressor (Seed Averaging):** Level-wise бустинг на 5 разных сидах для минимизации дисперсии. Основной фундамент бленда.
   - **Tabular MLP (ZILN Loss):** Нейросеть с кастомной функцией потерь Zero-Inflated Lognormal и QuantileTransformer для сглаживания выбросов.
   - **XGBoost (Log Target):** Асимметричный бустинг с глубокой L1/L2 регуляризацией для диверсификации предсказаний.
3. **Финальный Ансамбль:**
   - Ручной взвешенный бленд (80% CatBoost + 15% MLP + 5% XGBoost) на основе анализа OOF-метрик и устойчивости к переобучению.

## Как запустить

1. Установите зависимости: `pip install -r requirements.txt`
2. Поместите исходный файл `train.parquet` в папку `data/raw/`.
3. Запустите ноутбук `notebooks/1_data_v5.ipynb` для генерации фичей.
4. (Опционально) Для самостоятельного подбора гиперпараметров запустите `notebooks/3_catboost_optuna_v5.ipynb`.
5. Обучите все модели и сгенерируйте финальные сабмиты, выполнив `notebooks/2_train_blend_v5.ipynb`.
